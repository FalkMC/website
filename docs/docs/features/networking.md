# Networking

## Local IP

Your local IP address is displayed right on the server card, so you know exactly what address to give players on your LAN.

## Public IP

The panel can show your public IP (via an external API) so remote friends can connect.

## Port checker

A built‑in port checker lets you test if your server port is reachable from the internet, it will tell you if it's open, closed, or unknown.

## Port forwarding guide

For routers that don't support UPnP, the panel provides step‑by‑step instructions for common router models, with links to portforward.com.

## UPnP support (planned)

Automatically add and remove port mappings on your router, no more manual forwarding. FalkMC will detect compatible routers and handle the mappings for you.
