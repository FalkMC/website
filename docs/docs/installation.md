# Installation

## Download

1. Go to the [releases page](https://github.com/FalkMC) and download the latest `FalkMC-Panel.exe`.

## Run

2. Double‑click the `.exe` – no installation required. The panel will create a `servers/` folder in your Documents.

## First launch

3. On first run, FalkMC Panel will:
   - Create a `settings.json` file next to the `.exe`
   - Show you an empty server list
   - Wait for you to create your first server

## Need Java?

The panel requires Java 17 or higher to run servers. If you don't have it, download it from [Adoptium](https://adoptium.net/) or [Oracle](https://www.oracle.com/java/technologies/downloads/).

## Troubleshooting

- **"Java not found"** – make sure Java is installed and added to your PATH.
- **Port already in use** – change the server port in settings.
- **Antivirus warnings** – FalkMC Panel is open source; you can verify the code or add an exception.
